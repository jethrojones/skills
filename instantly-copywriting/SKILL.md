# Instantly Copywriting & Testing

Copy strategies, templates, and testing methodology for cold email campaigns.

## Copy Philosophy

1. **Short > Long** — Get to the point. One-sentence emails work.
2. **Soft CTA > Hard CTA** — "Mind if I share more info?" beats "Book a call"
3. **Vague can work** — Creates curiosity, doesn't reveal everything
4. **Specific > Generic** — Show you know their industry
5. **Value first** — Offer something (Loom, case study) before asking

## Anatomy of a Good Cold Email

```
[Personalization] — Show you did research
[Offer] — What you can do for them
[CTA] — One clear ask
```

**Example:**
```
Hey {{firstName}},

Out of the blue question — but I recorded a 30-second Loom showing how you could add $3M ARR to {{companyName}} like we did for [Client].

Mind if I send it over?
```

**Why it works:**
- Short (3 sentences)
- Soft CTA (not asking for call)
- Specific value ($3M ARR)
- Social proof (like we did for X)
- Offers value upfront (Loom)

## One-Sentence Email Template

```
Quick question — would {{companyName}} be open to a tool that can help you get 500 meetings/month?

Mind if I send more info?
```

## Personalization Hierarchy

**Level 1 — Basic variables:**
```
{{firstName}}, {{companyName}}
```

**Level 2 — Segmented variables (resonating):**
```
We help [NICHE] [VALUE PROP]
→ "We help sustainable e-commerce stores grow"
```

**Level 3 — Research-based:**
```
Noticed [SPECIFIC THING FROM THEIR SITE/TWITTER]
→ "Your Twitter posts are amazing — have you thought about turning them into videos?"
```

**Level 4 — Custom content:**
```
I made a Loom specifically for {{companyName}} showing...
```

## Resonating Variables

Add as many as you can to make generic copy feel personal:

| Variable Type | Example |
|---------------|---------|
| Gender | "female founders" |
| Position | "CEOs", "Marketing Directors" |
| Location | "in LA", "UK-based" |
| Niche | "sustainable makeup brands" |
| Sub-niche | "Shopify stores", "SaaS companies" |
| Value prop | "grow", "scale", "automate" |
| Mission/values | "while putting the planet first" |
| Technology | "Shopify", "HubSpot users" |
| Timing | "before summer", "end of quarter" |
| Weather | "with the rain in Seattle..." |

**2 variables:** "We help e-commerce stores grow"
**8 variables:** "We help female founders in LA grow their sustainable makeup brands while putting the planet and people first"

## Testing Methodology

### Volume Benchmarks

| Metric | Target |
|--------|--------|
| Emails per test | 200-300 minimum |
| Positive response rate | 1 per 200 emails |
| Close rate | 1 per 2,500 emails sent |
| Open rate | 45%+ is healthy |

### What to Test

1. **Job titles** — Don't only target CEOs (most competitive)
2. **Company size** — SMB vs mid-market vs enterprise
3. **Location** — Different regions respond differently
4. **Industry sub-niches** — "E-commerce" vs "Sustainable beauty e-commerce"
5. **Copy length** — Long vs short
6. **CTA strength** — "Book a call" vs "Mind if I share?"
7. **Value prop angle** — Revenue vs time saved vs cost reduction

### Testing Process

1. Pick 10-15 copy templates from Instantly Accelerator
2. Adapt each to your offer
3. Run separate campaigns (200-300 emails each)
4. Track positive responses (not just replies)
5. Scale winners, kill losers
6. Keep testing new angles

## Using AI (ChatGPT)

**Shorten copy:**
> "Make this email shorter while keeping the main offer"

**Change tone:**
> "Rewrite this to sound more casual/professional"

**Generate variations:**
> "Give me 5 different ways to say 'Would you like to learn more?'"

**Spintax generation:**
> "Create spintax alternatives for: 'handle' in format {random|handle|X|Y}"

## Sending Limits

| Per Email Account | Daily Limit |
|-------------------|-------------|
| Cold emails | 30 |
| Warm-up emails | 20 |
| **Total** | **50** |

To send more volume: **Add more accounts, don't increase per-account limits**

## Sequence Structure

- **Step 1:** Main pitch (Day 0)
- **Step 2:** Follow-up, different angle (Day 3-4)
- **Step 3:** Value add or case study (Day 7)
- **Step 4:** Break-up or last chance (Day 14)

Pro tip: Personalize the ENTIRE sequence, not just the first email.
